## 3. 멈춘 지점과 바로 할 일

**US-001~US-007 완료. US-008 은 사용자 요청에 따라 "목차부터 만들고 한 장씩 완성" 방식으로 진행 중입니다. 목차·입안서·Ⅰ 결정(안)·Ⅱ 계획의 개요·Ⅲ 상위 및 관련계획 검토·Ⅳ 현황 및 여건분석·Ⅴ 배수시설 조성계획·Ⅵ 기초자료 조사서·Ⅶ 편입토지조서·Ⅷ 첨부서류·표지 완료(입안서 패키지 장 전부), 다음 장은 `chapters.json` 의 '대기' 중에서 정합니다.**

### 작업 방식 (2026-10-22 사용자 요청)
- 장별 진행 목록: `chapters.json` — 장마다 `status`(대기/작업중/완료)·`todo`·`note`. 한 장을 끝내면 `완료`로 바꾼다.
- 장 조립기: `src/compose/chapters/index.js` 의 `BUILDERS` 에 장 id 로 하나씩 등록한다(지금은 `pkg.toc` 목차만). 등록 안 된 장은 '들어갈 재료' 초안으로 보인다.
- **미리보기로 바로 확인**: `npm run preview` → http://127.0.0.1:4173 . 코드·문안(library)·골격(templates)·chapters.json·project.json 을 저장하면 자동으로 다시 조립하고 브라우저가 새로 고쳐진다. Claude 데스크톱 앱에서는 내장 브라우저 설정 `ipansuh-preview`(`인허가/.claude/launch.json`)로 연다.
- 샘플 프로젝트: `examples/교동삼산.project.json` (경로는 이 파일 기준). 필지는 시설별로 지정할 수 있다 — 교동 = 현황분석 도구 필지 엑셀(`"facility": "교동배수지"`), 삼산 = 샘플 결정안 표. 용도지역은 현황분석 보고서에서 읽고, 없으면 `"zones": {"삼산배수지": {"계획관리지역": 면적}}` 로 넣으면 Ⅲ장 관련법규 판정이 채워진다. 화면에서 입력할 값(급수지역·입안기관 등)은 이 파일의 `vars`, 사실 수정은 `facts`, 절 매핑 수정은 `mapping` 에 넣는다.

### 이전 메모 (US-008 원래 계획)

- US-008 에서 쓸 재료가 모두 준비돼 있습니다.
  - 사업 사실: `extractFacts()` (`src/extract/facts.js`)
  - 편입토지·집계: `readParcels()`/`aggregate()` (`src/extract/parcels.js`)
  - 결정조서·사유서: `buildDecision()` + `decisionToMarkdown()` (`src/plan/decision.js`)
  - 절 매핑: `mapSections()` + `templates/water-supply.json` (`src/plan/mapper.js`)
  - 문안: `buildNarrative()` + `sectionToMd()` (`src/plan/narrative.js`, `library/*.json`). 문안 항목의 `targets` 가 템플릿 절 id(`pkg.app.reason`, `pkg.2.2`, `pkg.3.3` 등)를 가리킵니다.
- 할 일: `src/compose/index.js` 의 `composePackage(project)` — 템플릿 순서대로 파트를 만들고, design/status 절은 매핑된 원본을 옮기고, library/generated 절은 위 함수 결과로 채우고, 못 찾은 절은 `[작성 필요: …]` 로 남깁니다(prd.json US-008 인수 기준).
- 끝나면 `prd.json` 의 해당 스토리를 `"passes": true` 로 바꾸고 `progress.txt` 를 갱신합니다.
