# 인허가 폴더 — 진행 중인 작업

## 도시계획시설결정 입안서류 자동작성기 (`입안서_자동작성/`)

설계보고서 + 현황분석 보고서를 등록하면 입안서류 전체(HWPX)를 자동 조립하는 프로그램을 만들고 있다. **입안서 패키지 장(목차·표지·입안서·Ⅰ~Ⅷ) 완료, 남은 것은 검토서 3종(환경성·교통성·경관성)과 HWPX 출력(US-009~)**이며 (2026-10-23). 장별 진행은 `입안서_자동작성/chapters.json`, 결과는 `npm run preview` 로 바로 확인한다., 어느 계정·세션에서든 아래 순서로 이어서 진행한다.

### 시작할 때 먼저 읽을 것 (순서대로)
1. `입안서_자동작성/이어서하기.md` — 재개 절차, 환경 확인, 다음 할 일
2. `입안서_자동작성/작업정리.md` — 지금까지의 분석·결정·진행 상태
3. `입안서_자동작성/progress.txt` — 스토리별 진행 기록
4. `입안서_자동작성/prd.json` — 스토리 14개와 인수 기준 (`passes:false` 첫 스토리부터)

### 이 작업의 규칙
- 사용자는 "전체 자동 생성"을 원했다(검토서 포함). 출력 형식·실행 형태·시설 종류는 사용자가 답하지 않아 기본값(HWPX / 로컬 웹앱+bat / 수도 중심)으로 진행 중이다. 사용자가 바로잡으면 따른다.
- 입력 자료: `설계보고서/`(교동·삼산 1~7장 HWP), `현황분석 보고서/`(다른 지역 여수 샘플, 필지 엑셀 포함). 정답 비교용 샘플: `도시계획 시설결정 입안신청서_교동삼산.pdf`, `도시계획시설결정/*.hwp`. 이 파일들은 크고(최대 90MB) 설계 자료이므로 **git에 올리거나 복사하지 않는다.**
- 보고서에 없는 내용(교통량 조사, 조망 시뮬레이션 등)은 지어내지 않고 `[외부 자료 필요]`/`[작성 필요]`로 표시한다.
- 파일은 쓰기·수정 도구로 작성한다. 셸 명령에 백슬래시가 든 코드를 넣으면 풀려서 깨진다.
- `../launcher/tools.json` 은 사용자가 작업 중인 파일이라 수정하지 않는다.
- 시험은 `cd 입안서_자동작성 && npm test` (샘플 파일이 없으면 해당 시험은 skip).
