# 일괄 파일명 변경기

폴더 안 여러 파일의 이름 **앞/뒤에 문구나 순번을 한 번에** 추가하는 윈도우 프로그램.

## 기능
- **폴더 선택 / 파일 추가 / 드래그&드롭**으로 파일 불러오기
- **앞에 추가**, **뒤에 추가**(확장자는 그대로 유지)
- **순번 매기기**: 위치(앞/뒤) · 시작번호 · 간격 · 자릿수(0채움) · 구분자
- **미리보기**: `현재 이름 → 변경 후 이름`을 표로 확인, 포함/제외 체크
- **찾기·바꾸기**, **앞/뒤 글자 삭제**
- **정렬**: 이름순 · 자연정렬(숫자 인식) · 수정일순 · 크기순 · 추가순 · 역순
- **안전장치**: 이름 충돌·사용불가 문자·경로 길이 초과를 감지해 실행 차단,
  덮어쓰기 방지, **실행 취소(되돌리기)**
- **설정 자동 저장**: 종료 시 입력값을 저장하고 다음 실행에 복원
  (`%APPDATA%\일괄파일명변경기\settings.json`)

## 실행 (개발 환경)
```
pip install -r requirements.txt
python main.py
```

## exe 빌드
```
build_release.bat
```
빌드 결과: `dist\일괄파일명변경기\일괄파일명변경기.exe` (폴더째 배포)

## 테스트
```
python test_renamer_core.py
```

## 구조
| 파일 | 설명 |
|------|------|
| `renamer_core.py` | 이름 변경 엔진(순수 표준라이브러리, 테스트 대상) |
| `main.py` | tkinter GUI (아이콘·설정저장 포함) |
| `make_icon.py` | 아이콘 생성기 (`icon.ico`) |
| `test_renamer_core.py` | 엔진 단위 테스트 |
| `파일명변경기.spec` | PyInstaller 설정(onedir) |
| `build_release.bat` | 빌드 스크립트 |
