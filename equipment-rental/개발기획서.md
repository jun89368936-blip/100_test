# 부서 공유 물품 대여 관리 시스템 — 개발기획서

> **문서 유형:** 기능 요구사항 명세서 (Functional Requirements Specification)
> **작성일:** 2026년 6월
> **버전:** 1.0

## 1. 프로젝트 개요

### 1.1 배경 및 목적

부서 내 공유 물품(드론, 노트북 등)의 대여·반납 현황을 수기 또는 구두로 관리하던 방식에서 발생하는 문제(이중 대여, 분실, 미반납 등)를 해결하기 위해 웹 기반 통합 관리 플랫폼을 구축한다.

### 1.2 서비스 목표

- 부서원 누구나 스마트폰·PC에서 즉시 접속하여 물품 대여 신청 가능
- 관리자가 물품·대여·사용자를 한 화면에서 통합 관리
- 대여 현황 실시간 파악 및 미반납 알림 자동화

### 1.3 서비스 정보

| 항목 | 내용 |
|------|------|
| 서비스 URL | https://equipment-rental-ru95.onrender.com |
| 대상 사용자 | 물산업부문 부서원 (약 253명) |
| 관리 물품 | 드론 3대, 노트북 2대 (추후 추가 가능) |

## 2. 사용자 정의

### 2.1 사용자 유형

| 유형 | 접근 방법 | 권한 |
|------|----------|------|
| **일반 사용자** | 사번 + 비밀번호 로그인 | 대여·반납 신청, 달력 조회, 이력 조회, 비밀번호 변경 |
| **관리자** | PIN 번호 입력 | 일반 사용자 권한 + 물품·대여·사용자 관리 |

### 2.2 계정 정책

- **아이디:** 사번 (예: `214047`)
- **초기 비밀번호:** 사번과 동일
- **비밀번호 변경:** 사용자 직접 변경 가능 / 관리자 초기화 가능
- **비밀번호 저장 방식:** werkzeug pbkdf2 해싱 (단방향 암호화)

## 3. 기능 요구사항

### 3.1 공통 기능

#### 로그인 / 로그아웃
- 사번 + 비밀번호 입력 후 로그인
- 로그인하지 않으면 모든 화면 접근 불가 (`/login`으로 리다이렉트)
- 로그아웃 시 세션 초기화

#### 비밀번호 변경
- 현재 비밀번호 확인 후 새 비밀번호 변경
- 새 비밀번호 확인 불일치 또는 4자리 미만 시 오류 메시지

---

### 3.2 일반 사용자 기능

#### 내 대여 현황 (메인 화면 상단)
- 로그인 시 본인이 현재 빌려간 물품 목록 즉시 표시
- 반납 지연 항목: 빨간색 경고 표시
- 오늘 반납 예정 항목: 주황색 알림 표시
- 해당 화면에서 바로 반납 처리 가능

#### 물품 대여
- 대여 가능한 물품 목록 카드형으로 표시
- 대여일 + 반납일 날짜 선택 후 대여 신청
- 날짜 범위가 겹치면 대여 불가 (오류 메시지 표시)
- 반납 예정일 당일에는 새 대여 시작 허용
- 대여자 이름은 로그인 계정에서 자동 적용 (입력 불필요)

#### 물품 반납
- 메인 화면에서 반납하기 버튼 클릭으로 즉시 반납 처리

#### 달력 보기
- 월간 달력에 전체 대여 일정 표시
- 물품별 색상 구분
- 이벤트 클릭 시 대여자·기간 상세 정보 표시

#### 대여 이력 조회
- 전체 대여 기록 최신순 목록 표시
- 상태별 색상 구분 (대여 중 / 반납 완료)
- 엑셀 파일 다운로드 (`.xlsx`, 날짜·스타일 포함)

---

### 3.3 관리자 기능

> 관리자 PIN 로그인 후 활성화. 일반 사용자에게는 관리자 메뉴 비표시.

#### 관리자 대시보드
- 전체 물품 수 / 대여 가능 / 대여 중 / 전체 대여 건수 통계 카드
- 현재 대여 중인 물품 목록 + 강제 반납 버튼

#### 물품 관리
- 물품 추가 (물품명 + 종류 선택)
- 물품 삭제 (대여 중인 물품은 삭제 불가)
- **표시 순서 조정:** ▲ ▼ 버튼으로 순서 변경 → 메인 화면 카드 순서에 즉시 반영

#### 대여 관리
- 전체 대여 이력 목록 (필터: 전체 / 대여 중 / 반납 완료)
- 관리자 직접 대여 등록
- 강제 반납 처리
- 개별 기록 삭제 / 체크박스 다중 선택 삭제 / 전체 삭제

#### 부서원 계정 관리
- 부서원 목록 조회 (아이디 + 이름)
- 개별 계정 추가 (아이디 + 이름 + 초기 비밀번호)
- 개별 계정 삭제
- 개별 비밀번호 초기화 (새 비밀번호 직접 지정)
- **명단 일괄 등록:** 물산업부문 253명 한 번에 등록 (사번 = 아이디 = 초기 비밀번호)

---

### 3.4 알림 기능

- 대여 또는 반납 발생 시 텔레그램 봇으로 자동 알림 전송
- 수신자 복수 지정 가능 (쉼표 구분 CHAT_ID)
- 알림 내용: 물품명, 대여자/반납자, 날짜

## 5. 데이터베이스 설계

### 5.1 items 테이블 (물품)

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | INTEGER PK | 물품 고유 ID |
| name | TEXT | 물품명 (예: 드론 1호) |
| type | TEXT | 종류 (drone / laptop / camera / etc) |

### 5.2 rentals 테이블 (대여 이력)

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | INTEGER PK | 대여 고유 ID |
| item_id | INTEGER FK | 물품 ID |
| borrower_name | TEXT | 대여자 이름 |
| rented_at | TEXT | 대여일 (YYYY-MM-DD) |
| due_date | TEXT | 반납 예정일 (YYYY-MM-DD) |
| returned_at | TEXT | 실제 반납일시 (NULL = 대여 중) |

### 5.3 users 테이블 (부서원 계정)

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | INTEGER PK | 사용자 고유 ID |
| username | TEXT UNIQUE | 아이디 (사번) |
| password_hash | TEXT | 해싱된 비밀번호 |
| display_name | TEXT | 표시 이름 (성명) |

## 7. 환경 변수

| 키 | 설명 | 기본값 |
|----|------|--------|
| `DATABASE_URL` | PostgreSQL 연결 문자열 | 없으면 SQLite 사용 |
| `ADMIN_PIN` | 관리자 PIN 번호 | `1234` |
| `SECRET_KEY` | Flask 세션 암호화 키 | 기본값 있음 (변경 권장) |
| `TELEGRAM_BOT_TOKEN` | 텔레그램 봇 토큰 | 없으면 알림 비활성 |
| `TELEGRAM_CHAT_ID` | 알림 수신 채팅 ID (쉼표 구분 복수 가능) | 없으면 알림 비활성 |
| `RENDER_EXTERNAL_URL` | Render 서비스 URL (self-ping용) | Render가 자동 주입 |

## 10. 운영 가이드

### 초기 설정 (Render 배포 후)

1. 관리자 모드 접속: `/admin/login` → PIN `1234` (환경변수 `ADMIN_PIN`으로 변경 권장)
2. 부서원 관리 → **🚀 명단 일괄 등록** 클릭 → 253명 자동 등록
3. 물품 관리 → 드론/노트북 추가

### 비밀번호 분실 처리

1. 관리자 모드 → 부서원 관리
2. 해당 사용자 행의 새 비밀번호 입력 → **초기화** 클릭

### 물품 추가/삭제

- 관리자 모드 → 물품 관리에서 추가 (대여 중인 물품은 삭제 불가)

### 텔레그램 알림 수신자 추가

- Render 대시보드 → Environment → `TELEGRAM_CHAT_ID` 값에 쉼표로 추가
  - 예: `111111,222222,333333`
