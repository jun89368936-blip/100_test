## 일반 사용자 기능

### 1. 대여 현황 확인

메인 화면에서 물품별 현재 상태를 한눈에 확인할 수 있습니다.

- **대여 가능** (초록색 뱃지) — 지금 바로 대여 가능
- **대여 중** (주황색 뱃지) — 누군가 사용 중, 대여자 이름과 반납 예정일 표시

---

### 2. 물품 대여하기

1. 메인 화면에서 원하는 물품의 **대여하기** 버튼 클릭
2. 아래 정보 입력:
   - **대여자 이름** — 본인 이름 입력
   - **대여일** — 사용 시작일 선택 (기본값: 오늘)
   - **반납일** — 반납 예정일 선택 **(필수)**
3. **📤 대여하기** 버튼 클릭

> **기간 겹침 안내:** 다른 사람이 같은 날짜에 이미 대여 중이면 등록이 거부됩니다. 단, 반납 예정일 당일부터 새로 대여하는 것은 허용됩니다.

---

### 3. 물품 반납하기

1. 메인 화면에서 반납할 물품의 **✅ 반납하기** 버튼 클릭
2. 즉시 반납 처리 완료

---

### 4. 달력으로 대여 현황 보기

왼쪽 사이드바 **📅 달력 보기** 클릭

- 월간/목록 형태로 전체 대여 일정 확인 가능
- 물품별로 색상 구분
- 이벤트 클릭 시 대여자·기간 상세 정보 표시

---

### 5. 대여 이력 조회

왼쪽 사이드바 **📋 대여 이력** 클릭

- 전체 대여 기록을 최신순으로 확인
- 상태별 색상: **대여 중** (주황), **반납완료** (초록)

---

### 6. 대여 이력 엑셀 출력

**대여 이력** 화면 우측 상단 **📊 엑셀 다운로드** 클릭

- 파일명: `대여이력_YYYYMMDD.xlsx`
- 포함 내용: 물품명, 종류, 대여자, 대여일, 반납 예정일, 상태
- 날짜 형식: `26년 06월 16일`

## 관리자 기능

### 관리자 모드 접속

1. 사이드바 하단 **🔐 관리자 모드** 클릭
2. PIN 번호 입력 후 로그인
3. 보라색 사이드바의 관리자 전용 화면으로 전환

> PIN 번호를 모르면 시스템 관리자에게 문의하세요.

---

### 관리자 대시보드

- 전체 물품 수 / 대여 가능 / 대여 중 / 전체 대여 건수 통계
- 현재 대여 중인 물품 목록 — **반납 처리** 버튼으로 강제 반납 가능
- 물품 관리 / 대여 관리 바로가기

---

### 물품 관리

사이드바 **📦 물품 관리** 클릭

**물품 추가**
1. 물품명 입력 (예: 드론 4호)
2. 종류 선택 (드론 / 노트북 / 카메라 / 기타)
3. **추가** 버튼 클릭

**물품 삭제**
- 현재 대여 중이 아닌 물품만 삭제 가능
- 해당 물품의 **삭제** 버튼 클릭

---

### 대여 관리

사이드바 **📋 대여 관리** 클릭

**직접 대여 등록** (관리자가 대신 등록)
1. 물품 선택 → 대여자 이름 → 대여일 → 반납 예정일 입력
2. **등록** 버튼 클릭

**강제 반납**
- 대여 중인 항목의 **반납** 버튼 클릭
- 대여자가 직접 반납하지 않아도 관리자가 처리 가능

**기록 삭제**
- 잘못 입력된 대여 기록의 **삭제** 버튼 클릭
- 삭제된 기록은 복구되지 않으니 주의

**필터**
- **전체 / 대여 중 / 반납 완료** 버튼으로 목록 필터링

## 알림 기능

대여 또는 반납이 발생하면 관리자 텔레그램으로 자동 알림이 전송됩니다.

- 📦 대여 알림: `[물품명] 대여 — 대여자 이름 (대여일시)`
- ✅ 반납 알림: `[물품명] 반납 — 대여자 이름 (반납일시)`

## 자주 묻는 질문 (FAQ)

**Q. 반납 예정일이 지났는데 반납이 안 됐어요.**
→ 메인 화면에서 직접 반납하거나, 관리자에게 강제 반납 처리를 요청하세요.

**Q. 같은 날 두 사람이 같은 물품을 대여할 수 있나요?**
→ 날짜가 겹치면 불가합니다. 기간이 연속되는 경우(A가 6/20 반납, B가 6/20 대여)는 허용됩니다.

**Q. 접속이 너무 느려요.**
→ 무료 서버 특성상 장시간 미사용 후 첫 접속은 30~50초 소요될 수 있습니다. 잠시 기다려 주세요.

**Q. 물품을 추가하고 싶어요.**
→ 관리자 모드 → 물품 관리에서 추가할 수 있습니다.

**Q. 대여 이력을 보고서로 만들고 싶어요.**
→ 대여 이력 화면에서 **📊 엑셀 다운로드** 버튼을 사용하세요.
