## 1. 처음 접속하기

웹 브라우저(Chrome, Edge, Safari 등)에서 아래 주소로 접속합니다.

```
https://equipment-rental-ru95.onrender.com
```

> **참고:** 서버가 절전 상태일 경우 처음 접속 시 10~20초 정도 로딩이 걸릴 수 있습니다. 잠시 기다리면 자동으로 열립니다.

스마트폰에서도 위 주소를 브라우저에 입력하면 동일하게 사용할 수 있습니다.

## 2. 로그인 / 로그아웃

### 로그인

처음 접속하면 로그인 화면이 나타납니다.

| 입력 항목 | 내용 |
|----------|------|
| **아이디** | 본인 사번 (예: `214047`) |
| **비밀번호** | 초기 비밀번호는 사번과 동일 |

① 아이디(사번)와 비밀번호를 입력합니다.
② **로그인** 버튼을 클릭합니다.
③ 로그인 성공 시 메인 화면으로 이동합니다.

> ⚠️ **비밀번호를 잊었다면?** 물품 담당자(관리자)에게 초기화를 요청하세요.

### 로그아웃

화면 우측 상단의 **로그아웃** 링크를 클릭합니다.

## 3. 비밀번호 변경

초기 비밀번호(사번)는 보안을 위해 변경하는 것을 권장합니다.

① 화면 우측 상단의 **🔑 비밀번호 변경** 링크를 클릭합니다.
② 아래 항목을 입력합니다.

| 항목 | 설명 |
|------|------|
| 현재 비밀번호 | 지금 사용 중인 비밀번호 입력 |
| 새 비밀번호 | 새로 사용할 비밀번호 (4자리 이상) |
| 새 비밀번호 확인 | 위와 동일하게 다시 입력 |

③ **변경하기** 버튼을 클릭합니다.
④ 변경 완료 시 메인 화면으로 이동합니다.

> ⚠️ 비밀번호는 4자리 이상으로 설정해야 합니다.

## 4. 물품 대여하기

① 메인 화면에서 대여하려는 물품 카드를 확인합니다.
- **대여 가능** 상태인 물품만 대여 신청을 할 수 있습니다.
- **대여 중** 상태인 물품은 현재 다른 팀원이 사용 중입니다.

② 대여할 물품 카드 아래에 있는 날짜 입력란에 대여 정보를 입력합니다.

| 항목 | 설명 |
|------|------|
| **대여일** | 물품을 가져가는 날짜 |
| **반납 예정일** | 물품을 돌려줄 날짜 |

> ⚠️ **예약 가능 기간:** 오늘부터 최대 31일 이내까지만 선택할 수 있습니다.

③ **대여하기** 버튼을 클릭합니다.
④ 대여자 이름은 로그인한 계정 이름으로 자동 등록됩니다.

> ⚠️ **대여 불가 안내:** 선택한 날짜 범위에 이미 다른 예약이 있으면 대여가 거절됩니다. 달력 화면에서 다른 팀원의 일정을 확인한 뒤 날짜를 조정하세요.

---

## 5. 물품 반납하기

① 메인 화면 상단의 **내가 빌려간 물품** 영역을 확인합니다.
② 반납할 물품 옆의 **✅ 반납** 버튼을 클릭합니다.
③ 반납이 완료되면 해당 물품이 목록에서 사라지고 **대여 가능** 상태로 바뀝니다.

---

## 6. 대여 취소하기

테스트 신청이나 실수로 대여를 신청한 경우 본인이 직접 취소할 수 있습니다.

① 메인 화면 상단의 **내가 빌려간 물품** 영역을 확인합니다.
② 취소할 물품 옆의 **✕ 취소** 버튼을 클릭합니다.
③ 확인 팝업에서 **확인**을 클릭하면 취소됩니다.

> **참고:**
> - 취소된 기록은 관리자 화면에 **취소** 상태로 보존됩니다. (완전 삭제 아님)
> - 이미 반납한 대여는 취소할 수 없습니다.
> - 타인의 대여는 취소할 수 없습니다.

---

## 7. 내 대여 현황 확인

메인 화면 상단에 **내가 빌려간 물품** 카드가 표시됩니다.

| 표시 색상 | 의미 |
|----------|------|
| 일반 (흰색) | 정상 대여 중 |
| 🟠 주황색 | 오늘 반납 예정 |
| 🔴 빨간색 | 반납 예정일이 지난 연체 상태 |

현재 대여 중인 물품이 없으면 이 카드는 표시되지 않습니다.

## 8. 달력으로 대여 일정 보기

좌측 메뉴에서 **달력** 을 클릭하면 월간 달력에서 전체 대여 일정을 한눈에 볼 수 있습니다.

- 물품마다 다른 색상으로 표시됩니다.
- 일정 블록을 클릭하면 **대여자 이름, 대여 기간** 상세 정보가 팝업으로 나타납니다.
- 좌우 화살표로 월을 이동할 수 있습니다.

> 💡 **Tip:** 대여 신청 전 달력에서 원하는 날짜가 비어 있는지 먼저 확인하면 편리합니다.

## 9. 대여 이력 조회 및 엑셀 다운로드

좌측 메뉴에서 **대여 이력** 을 클릭합니다.

- 전체 대여 기록이 최신순으로 표시됩니다.
- **대여 중** / **반납완료** 상태를 색상으로 구분합니다.

### 엑셀 다운로드

화면 우측 상단의 **📥 엑셀 다운로드** 버튼을 클릭하면 전체 이력을 `.xlsx` 파일로 저장할 수 있습니다.

## 10. 관리자 기능

> 이 섹션은 물품 담당자(관리자)를 위한 내용입니다.

### 관리자 로그인

메인 화면 좌측 하단의 **🛡️ 관리자 모드** 링크를 클릭한 후 PIN 번호를 입력합니다.
관리자 모드에서는 사이드바가 **보라색**으로 바뀝니다.

---

### 10-1. 대시보드

관리자 로그인 후 첫 화면입니다.

#### 당일 현황
오늘 날짜 기준 **전체 물품 / 대여 가능 / 대여 중** 현황을 카드로 표시합니다.

#### 현재 대여 중인 물품
지금 대여 중인 물품 목록과 대여자, 반납 예정일을 보여줍니다.
- **반납 처리** 버튼으로 강제 반납 처리를 할 수 있습니다.

#### 물품별 월별 대여일수
최근 6개월간 각 물품이 며칠 동안 대여되었는지 표로 표시됩니다.

| 항목 | 설명 |
|------|------|
| 물품별 행 | 각 물품의 월별 대여일수 |
| 합계 행 | 전체 물품의 월별 합산 대여일수 |
| 파란색 숫자 | 대여 기록이 있는 날수 |

- 우측 상단 **📥 엑셀 출력 (12개월)** 버튼으로 12개월치 데이터를 엑셀로 다운로드할 수 있습니다.
- 취소된 대여는 일수에서 제외됩니다.

---

### 10-2. 물품 관리

**관리자 메뉴 → 물품 관리** 에서 물품을 추가하거나 삭제할 수 있습니다.

#### 물품 추가
① 물품명을 입력합니다. (예: `드론 4호`)
② 종류를 선택합니다. (드론 / 노트북 / 카메라 / 기타)
③ **추가** 버튼을 클릭합니다.

#### 물품 삭제
- 현재 **대여 중이 아닌** 물품만 삭제할 수 있습니다.
- 물품 행 오른쪽의 **삭제** 버튼을 클릭합니다.

#### 표시 순서 변경
- 물품 행 왼쪽의 **▲ ▼** 버튼으로 메인 화면에 표시되는 순서를 조정합니다.

---

### 10-3. 대여 관리

**관리자 메뉴 → 대여 관리** 에서 전체 대여 이력을 관리합니다.

#### 물품별 이력 조회
- 상단 **물품 선택** 드롭다운에서 원하는 물품을 선택하면 해당 물품의 대여 이력만 표시됩니다.
- **✕ 초기화** 를 클릭하면 전체 목록으로 돌아갑니다.

#### 상태 필터
- **전체 / 대여 중 / 반납 완료 / 취소** 버튼으로 원하는 상태만 필터링할 수 있습니다.
- 사용자가 취소한 대여는 **취소** 상태로 표시되며 이력이 보존됩니다.

#### 엑셀 다운로드
- **📥 엑셀 다운로드** 버튼을 클릭합니다.
- 물품이 선택된 상태라면 해당 물품 이력만, 전체 보기 상태라면 전체 이력이 다운로드됩니다.

#### 대여 직접 등록
- 관리자가 직접 대여를 등록할 때 사용합니다. (물품, 대여자 이름, 대여일, 반납 예정일 입력)

#### 강제 반납 / 삭제
- 각 대여 행 오른쪽의 **반납** 버튼으로 강제 반납 처리합니다.
- **삭제** 버튼으로 해당 기록을 삭제합니다.
- 여러 건을 한꺼번에 삭제하려면 체크박스로 선택 후 **선택 삭제** 를 클릭합니다.

---

### 10-4. 부서원 관리

**관리자 메뉴 → 부서원 관리** 에서 계정을 관리합니다.

#### 명단 일괄 등록
- **🚀 명단 일괄 등록** 버튼을 클릭하면 물산업부문 전체 부서원 253명이 한 번에 등록됩니다.
- 이미 등록된 계정은 중복 등록되지 않습니다.
- 초기 비밀번호는 사번과 동일합니다.

#### 개별 계정 추가
① 아이디(사번), 이름, 비밀번호를 입력합니다.
② **추가** 버튼을 클릭합니다.

#### 비밀번호 초기화
- 비밀번호를 잊은 부서원의 새 비밀번호를 직접 지정합니다.
- 해당 사용자 행의 입력란에 새 비밀번호를 입력하고 **초기화** 버튼을 클릭합니다.

#### 계정 삭제
- 해당 사용자 행의 **삭제** 버튼을 클릭합니다.

---

### 10-5. 달력 보기 (관리자)

**관리자 메뉴 → 달력 보기** 에서 전체 대여 일정을 월간 달력으로 확인할 수 있습니다.

- 물품별 색상으로 구분되어 표시됩니다.
- 일정 블록을 클릭하면 **대여자, 기간, 상태** 상세 정보가 팝업으로 표시됩니다.

## 11. 자주 묻는 질문 (FAQ)

**Q. 처음 접속했는데 로딩이 너무 오래 걸려요.**
A. 서버가 절전 모드에서 깨어나는 중입니다. 30초 정도 기다리면 정상적으로 열립니다.

---

**Q. 로그인이 안 돼요.**
A. 아이디는 사번(숫자), 초기 비밀번호도 사번입니다. 이전에 비밀번호를 변경했다면 변경된 비밀번호를 입력하세요. 그래도 안 되면 관리자에게 초기화를 요청하세요.

---

**Q. 대여 신청을 했는데 "이미 대여 중"이라고 나와요.**
A. 선택한 날짜 범위에 다른 팀원의 대여 일정이 겹쳐 있습니다. 달력 화면에서 빈 날짜를 확인한 뒤 다시 신청하세요.

---

**Q. 대여 날짜를 한 달 넘게 선택하고 싶어요.**
A. 예약 가능 기간은 오늘부터 31일 이내로 제한되어 있습니다. 장기 대여가 필요한 경우 관리자에게 직접 등록을 요청하세요.

---

**Q. 실수로 대여 신청을 했어요. 취소할 수 있나요?**
A. 네, 메인 화면의 **내가 빌려간 물품** 에서 **✕ 취소** 버튼을 클릭하면 됩니다. 단, 이미 반납 처리된 대여는 취소할 수 없습니다.

---

**Q. 취소한 기록이 관리자에게도 보이나요?**
A. 네, 취소한 대여는 삭제되지 않고 관리자 대여 관리 화면에 **취소** 상태로 보존됩니다.

---

**Q. 반납했는데 아직 "대여 중"으로 표시돼요.**
A. 페이지를 새로고침(F5)하면 최신 상태로 업데이트됩니다.

---

**Q. 비밀번호를 잊었어요.**
A. 관리자에게 비밀번호 초기화를 요청하세요. 관리자가 새 비밀번호를 지정해드립니다.

---

**Q. 모바일에서도 사용할 수 있나요?**
A. 네, 스마트폰 브라우저에서 동일한 주소로 접속하면 사용 가능합니다.

---

**Q. 대여 이력을 엑셀로 받고 싶어요.**
A. 일반 사용자는 **대여 이력** 메뉴에서, 관리자는 **대여 관리** 메뉴 또는 **대시보드**에서 엑셀 다운로드 버튼을 클릭하세요. 대시보드의 엑셀은 물품별 월별 대여일수 통계입니다.
