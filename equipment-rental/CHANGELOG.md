- **GitHub:** https://github.com/jun89368936-blip/100_test (`equipment-rental/` 폴더)
- **개발 기간:** 2026년 6월

## 작업 이력

### Phase 1 — 기초 시스템 구축

**목표:** 물품 대여·반납을 처리하는 웹 앱 초기 구축

- Flask 기반 웹 앱 구조 설계
- SQLite DB 연동 (`items`, `rentals` 테이블)
- 물품 목록 조회 / 대여 / 반납 기능 구현
- 커스텀 CSS 스타일 적용 (사이드바 레이아웃)
- FullCalendar.js v6 달력 보기 추가
- 대여 이력 페이지 추가
- Telegram Bot API 알림 연동 (대여/반납 시 자동 알림)

---

### Phase 2 — 클라우드 배포 (Render.com)

**목표:** 인터넷 공개 접속 가능한 서비스로 배포

- PostgreSQL 지원을 위한 DB 추상화 레이어 구축 (`db.py`)
  - `_Row`, `_Cursor`, `_Connection` 래퍼 클래스
  - `?` → `%s` 플레이스홀더 자동 변환
  - SQLite(로컬) / PostgreSQL(클라우드) 자동 전환
- Render.com 무료 플랜 배포 설정 (`render.yaml`)
- gunicorn WSGI 서버 설정
- QR코드 생성 및 저장 (`qr_code.png`)

---

### Phase 3 — 관리자 모드 분리

**목표:** 일반 사용자와 관리자 기능 완전 분리

- 관리자 PIN 로그인 (`/admin/login`)
- 관리자 전용 사이드바 (보라색 테마)
- 관리자 대시보드 (`/admin`) — 통계 + 현재 대여 현황
- 물품 관리 (`/admin/items`) — 추가 / 삭제
- 대여 관리 (`/admin/rentals`) — 직접 등록 / 강제 반납 / 삭제
- 체크박스 다중 선택 삭제 / 전체 삭제 기능

---

### Phase 4 — 기능 고도화

**목표:** 사용 편의성 및 기능 추가

- **대여 방식 변경:** 단일 날짜 → 대여일 + 반납일 기간 입력
- **날짜 중복 체크:** DB 유니크 인덱스 → 날짜 범위 겹침 쿼리로 교체
  - 반납 예정일 당일 새 대여 허용 (strict overlap)
- **엑셀 내보내기:** 대여 이력 `.xlsx` 다운로드 (openpyxl, 스타일 적용)
- **다중 텔레그램 수신:** `TELEGRAM_CHAT_ID`를 쉼표 구분으로 여러 명 지원
- **콜드 스타트 방지:**
  - UptimeRobot 외부 핑 (5분 주기)
  - 앱 내 self-ping 데몬 스레드 (4분 주기, Render 환경에서만 동작)

---

### Phase 5 — 부서원 로그인 시스템

**목표:** 부서원 계정 기반 로그인으로 접근 통제

- `users` 테이블 추가 (`id`, `username`, `password_hash`, `display_name`)
- 로그인 페이지 (`/login`) — 사번 + 비밀번호
- 로그아웃 (`/logout`)
- `login_required` 데코레이터 — 미로그인 시 `/login` 리다이렉트
- 대여 시 로그인한 사용자명 자동 입력 (이름 직접 입력 제거)
- 메인 화면 상단 — 로그인 사용자 이름 + 로그아웃 링크 표시
- **내 대여 현황** — 로그인한 사람이 빌려간 물품을 메인 상단에 표시
  - 반납 지연(빨간색), 오늘 반납 예정(주황색) 강조
- 관리자 모드 메뉴 — 관리자 로그인한 경우에만 표시

---

### Phase 6 — 부서원 계정 관리

**목표:** 관리자가 부서원 계정을 직접 관리

- 부서원 관리 페이지 (`/admin/users`) — 목록 / 추가 / 삭제 / 비밀번호 초기화
- 명단 일괄 등록 기능 (`/admin/users/seed`)
  - 물산업부문 명단 CSV 253명 → 사번을 아이디·초기비밀번호로 등록
  - 비밀번호 해시 사전 계산 내장 (Render 타임아웃 방지)
- 관리자 사이드바 전 페이지에 부서원 관리 메뉴 추가

---

### Phase 7 — 개인 비밀번호 변경

**목표:** 일반 사용자가 직접 비밀번호 변경

- 비밀번호 변경 페이지 (`/profile/change-password`)
  - 현재 비밀번호 확인 → 새 비밀번호 입력 → 저장
  - 불일치 / 4자리 미만 오류 처리
- 메인 화면 상단에 **🔑 비밀번호 변경** 버튼 추가

---

### Phase 8 — 물품 순서 관리

**목표:** 관리자가 물품 표시 순서를 직접 지정

- `items` 테이블에 `sort_order` 컬럼 추가 (기존 DB 자동 마이그레이션)
- 물품 관리 페이지에 ▲ ▼ 버튼 추가
- 변경된 순서 → 메인 화면 물품 카드 배치에 즉시 반영
